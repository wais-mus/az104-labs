# AZ-104 Labs

Hands-on Azure labs I'm completing while studying for the **Microsoft Azure Administrator (AZ-104)** exam. Each folder is one lab with its templates, a deploy script and notes on what I learned.

## Labs

| # | Lab | Topics |
|---|-----|--------|
| 01 | [ARM template basics](01-arm-template-basics/) | ARM template structure, CLI deployments, storage accounts, parameters, outputs |

## Conventions

- **Region:** `westeurope`
- **Resource group names:** `rg-az104-<lab>-weu`
- **Tooling:** Azure CLI in Azure Cloud Shell (Bash)
- Every lab ends with a cleanup step that deletes its resource group.
